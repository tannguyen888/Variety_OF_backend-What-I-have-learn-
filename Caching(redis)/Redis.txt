Redis là gì?
-Redis là in-memory data, tối ưu vì chạy trên RAM
-thường dùng làm cache
-làm dữ liệu tạm thời

->> Redis đc so sánh nhanh hơn MySQL và PostgreSQL
do DB thường đọc disk -> chậm hơn

Redis thường đọc qua ram -> nhanh hơn

Thông thường Redis chỉ dùng để lưu cache, session login, OTP, queue, Realtime 
-> do tính chất của ram có tốc độ đọc cao và lưu tạm nên khi reset máy lại thì dữ liệu sẽ mất
---> không nên dùng Redis để lưu data quan trọng

// option sau tên 
(EX, NX, XX)
1. EX = Expire Time

 đặt thời gian tự xóa (seconds)

SET token abc EX 10

 nghĩa là:

key "token" sẽ tự xóa sau 10 giây

Use case:
OTP
login session
cache

Check:
TTL token
======================================
-------------------------------------
NX = Only Set If NOT Exists

👉 chỉ set nếu key chưa tồn tại

Example
SET username Erik NX
Nếu key chưa có:
✅ set thành công
Nếu key đã tồn tại:
❌ không overwrite
--------------------------------------

---------------------------
Use case cực quan trọng:
Distributed Lock
SET lock true NX EX 10

👉 nghĩa là:

chỉ 1 process lấy được lock
lock tự hết hạn sau 10s
-----------------------------
-----------------------------------------
XX = Only Set If EXISTS

👉 chỉ set nếu key đã tồn tại

Example
SET username Kyle XX
Nếu key tồn tại:

✅ update

Nếu key chưa tồn tại:

❌ fail
