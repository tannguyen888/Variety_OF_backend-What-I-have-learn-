1////// REST API
A REST API (Representational State Transfer Application Programming Interface) is an architectural style for designing networked applications. It enables communication between a client and a server over the internet using standard HTTP methods like GET, POST, PUT, PATCH, and DELETE. REST APIs are widely used for building web services due to their simplicity, scalability, and stateless nature.

2/////////// GrapQl Api 

GraphQL is an open‑source query language for APIs and a server‑side runtime that executes those queries using your existing data. Developed by Facebook in 2012 and open‑sourced in 2015, it offers a flexible, strongly‑typed schema that defines how data is structured and related, making APIs more predictable and efficient.

GraphQL:

query {
  recipe(id:1){
    name
  }
}

{
  "data": {
    "recipe": {
      "name": "Pho"
    }
  }
}


có thể lấy 2 object trong 1 request 
Lấy nhiều object

query {
  recipe(id:1){
    name
  }

  user(id:5){
    username
  }
}

///////// gRPC
RPC, short for gRPC Remote Procedure Calls, is an open-source framework developed by Google that facilitates efficient communication between distributed systems and microservices. It allows client applications to directly invoke methods on server applications as if they were local, simplifying the creation of distributed systems. gRPC uses Protocol Buffers (protobuf) as its default serialization mechanism and HTTP/2 as its transport protocol, offering significant performance and flexibility advantages over traditional RESTful APIs.

@GrpcService
public class RecipeGrpcService extends RecipeServiceGrpc.RecipeServiceImplBase {

    private final RecipeService recipeService;

    public RecipeGrpcService(RecipeService recipeService) {
        this.recipeService = recipeService;
    }

    @Override
    public void getRecipe(RecipeRequest request,
                          StreamObserver<RecipeResponse> responseObserver) {

        Recipe recipe = recipeService.findById(request.getId());

        RecipeResponse response = RecipeResponse.newBuilder()
                .setId(recipe.getId())
                .setName(recipe.getName())
                .setDescription(recipe.getDescription())
                .build();

        responseObserver.onNext(response);
        responseObserver.onCompleted();
    }

    @Override
    public void createRecipe(CreateRecipeRequest request,
                             StreamObserver<RecipeResponse> responseObserver) {

        Recipe recipe = recipeService.create(
                request.getName(),
                request.getDescription()
        );

        RecipeResponse response = RecipeResponse.newBuilder()
                .setId(recipe.getId())
                .setName(recipe.getName())
                .setDescription(recipe.getDescription())
                .build();

        responseObserver.onNext(response);
        responseObserver.onCompleted();
    }
}

🧠 5. Business Service (logic thật)

📍 service/RecipeService.java

@Service
public class RecipeService {

    private final RecipeRepository repository;

    public RecipeService(RecipeRepository repository) {
        this.repository = repository;
    }

    public Recipe findById(Long id) {
        return repository.findById(id)
                .orElseThrow(() -> new RuntimeException("Not found"));
    }

    public Recipe create(String name, String description) {
        Recipe recipe = new Recipe();
        recipe.setName(name);
        recipe.setDescription(description);

        return repository.save(recipe);
    }
}
